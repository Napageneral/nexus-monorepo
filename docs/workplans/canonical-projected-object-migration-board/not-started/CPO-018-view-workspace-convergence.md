# CPO-018 — View and Workspace Convergence

**State:** not started
**Depends on:** CPO-013
**Repositories:** nexus umbrella, MoonSleep apps and operations

## Goal

Move non-object product nouns out of the identity registry and bind their reads
to canonical objects.

## Scope

- Publish owner view catalogs for Customer, Partner, Customer Thread/Entity
  Communication History, Customer Issue, Tracking, and derived collections.
- Resolve every view field and relationship to a native subject, Facet
  Attachment, projected object, or evidence reference.
- Preserve stable routes and selection handles without creating semantic heads.
- Update applications and workspaces to consume canonical Current Heads.

## Acceptance

- No Read View remains in the canonical object registry.
- View routes resolve to exact constituent identities and revisions.
- If a view noun requires independent object behavior, it returns through the
  canonical Object eligibility review before registration.
- Historical URLs remain navigable through route aliases, not object aliases.

## Validation

- View composition, route compatibility, constituent revision, empty-state,
  inclusion/closure, and no-independent-head tests.
