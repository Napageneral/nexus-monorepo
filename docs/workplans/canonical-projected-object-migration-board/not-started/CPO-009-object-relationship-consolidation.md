# CPO-009 — Object and Relationship Consolidation

**State:** not started
**Depends on:** CPO-002
**Repositories:** nexus umbrella, MoonSleep

## Goal

Turn the exhaustive vocabulary census into one approved condensed object and
relationship vocabulary before permanent declarations are written.

## Scope

- Re-evaluate all 45 proposed Supply additions using the canonical Object
  eligibility test.
- Classify candidates as canonical object, attribute, event, relationship,
  revision, evidence membership, source metadata, receipt, or Read View.
- Consolidate all 149 Supplier relationship labels into reusable slots,
  historical aliases, genuinely domain-specific slots, or non-relationships.
- Remove External Product Reference as a canonical object candidate.
- Confirm the consequential Supply Shipment, Supply Transport Document,
  Batch/Lot/Manufacturing Run, and other remaining decisions with Tyler.

## Acceptance

- Every candidate noun and relationship has one explicit disposition.
- No packet-shaped row becomes canonical merely because it exists in a chapter.
- New relationship slots have stable direction, owner, target type,
  cardinality, and human wording.
- The resulting list is small enough to review as a whole before CPO-011.

## Validation

- Exhaustive census script proves zero unclassified Resource or relationship
  labels in the accepted Supplier and Claims corpora.
- Independent domain-language review.
