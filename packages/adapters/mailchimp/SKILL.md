# Mailchimp read-only adapter

Use this package for provider history, delivery evidence, campaign content, and
template discovery. Every exposed method is read-only.

Never use this adapter to send customer communication. A future send surface
requires a separate reviewed contract, authority boundary, and activation.

Treat provider delivery state as evidence, not proof that a message qualified
as an operational order update. Exact order/obligation binding and human
certification happen in the MoonSleep Customer Communications workspace.
